# ГОРОД AI — мобильный прототип (v0.7)

**Рабочее название.** Российский сервис поиска организаций и услуг по городам, с перспективой ИИ-помощника «Реши за меня».

## Текущий статус

- Главный экран, крупный центральный поиск с кнопкой «Поиск» и подсказками.
- Категории услуг, тестовые карточки организаций и карта.
- При открытии сайта по умолчанию подгружаются реальные организации из OpenStreetMap через публичный Overpass API. Демо-режим с вымышленными карточками остаётся доступным вручную.
- Геолокация (после разрешения), выбор города, фильтры, переход к маршруту и телефону.
- Пример рейтингов/отзывов (отзывы хранятся **только в текущем браузере**).
- Пример платного продвижения PRO/MAX — пока **только демонстрация**, оплаты не подключены.
- Базовая карта OpenStreetMap + Leaflet; у публичных серверов карт и Overpass есть ограничения по нагрузке и доступности.

## Новое в версии 0.7

- Обновлённый интерфейс в сдержанном футуристическом стиле; заголовок стал легче и читабельнее.
- Поиск по названию организации, категории, а также история последних пяти запросов.
- Стартовый справочник Белгорода: 18 организаций (1 ранее добавленная и 17 дополнительных) из общедоступных справочников и сайтов компаний. Для новых карточек без подтверждённых координат **не создаются вымышленные метки**.
- Встроен **переход** из поиска и карточек на официальный сайт Яндекс Карт с заранее заполненным запросом. Это **не API-интеграция**: результаты Яндекса не копируются, не отображаются внутри нашего приложения, рейтинги Яндекса не используются.
- Данные OpenStreetMap продолжают загружаться через Overpass API в режиме реальных организаций; публичные API могут быть временно недоступны.

Для отображения справочника Яндекса непосредственно в приложении потребуется лицензированный **API Поиска по организациям**, ключ и проверка лицензионных условий. Правила: https://yandex.ru/legal/maps_api/ru/ и https://yandex.ru/maps-api/products/geosearch-api

**Ещё не работает:** реальный генеративный ИИ, общий серверный рейтинг, личные аккаунты, оплата, онлайн-бронирование. Это не завершённый коммерческий сервис.

Доступны категории организаций, выбор города, карта, переходы на сайты и телефоны, а также кнопка «Обновить». Кеш на устройстве хранится до 4 часов, чтобы не перегружать бесплатные сервисы. Если внешние API недоступны, приложение показывает сохранённые данные (при наличии). Рейтинги реальных организаций пока не подключены: OpenStreetMap таких рейтингов не предоставляет.\n\n## Запуск

Откройте `index.html` в браузере. Для геолокации нужен HTTPS (или локальный сервер). Для загрузки карт и реальных мест нужен интернет. Публичная демонстрация через GitHub Pages:

1. Перейти в **Settings → Pages**.
2. В разделе **Build and deployment** выбрать **Deploy from a branch**.
3. Указать **main** и **/(root)**, сохранить.
4. После публикации открыть адрес, который покажет GitHub Pages. Иногда появление страницы занимает несколько минут.

Название репозитория сейчас заканчивается точкой: `gorod-ai-mvp.`. Если это случайно, переименуйте репозиторий в `gorod-ai-mvp` через **Settings → General → Repository name**, тогда будет более аккуратный URL. Сначала можно опубликовать и без переименования.

## Юридические и технические замечания

Данные организаций из OpenStreetMap распространяются по ODbL и требуют соблюдения условий лицензии и атрибуции. Для масштабного коммерческого запуска потребуется надёжный провайдер тайлов, управляемый источник данных, серверная инфраструктура, модерация отзывов и соблюдение требований к персональным данным.

Не храните в этом публичном репозитории пароли, токены, API-ключи и персональные данные.
